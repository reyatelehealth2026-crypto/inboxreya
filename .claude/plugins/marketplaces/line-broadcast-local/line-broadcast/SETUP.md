# line-broadcast plugin — Setup guide (portable bundle)

Slash commands `/broadcast`, `/update-products`, `/broadcast-list`, `/broadcast-auto` สำหรับสร้าง LINE broadcast จาก inbox.re-ya.com + CNY Manager. Cache-first (~70ms / broadcast), 2 สินค้า/bubble layout.

## Install (Claude Code)

1. **Extract** zip ลงที่:
   - macOS / Linux: `~/.claude/plugins/marketplaces/line-broadcast-local/line-broadcast/`
   - Windows:       `%USERPROFILE%\.claude\plugins\marketplaces\line-broadcast-local\line-broadcast\`
   ```bash
   mkdir -p ~/.claude/plugins/marketplaces/line-broadcast-local
   unzip line-broadcast-plugin.zip -d ~/.claude/plugins/marketplaces/line-broadcast-local
   ```

2. **Install deps** (ครั้งเดียว — สำหรับ XLSX export):
   ```bash
   cd ~/.claude/plugins/marketplaces/line-broadcast-local/line-broadcast
   npm install
   ```

3. **Restart Claude Code** → ตรวจว่าเห็น `/broadcast`, `/update-products` ใน slash command list

## Auth setup (project-level)

ในโปรเจ็คที่จะใช้ broadcast (cwd ตอนรัน command):

1. Login `https://inbox.re-ya.com` ใน browser
2. F12 → Application → Cookies → copy `__Secure-authjs.session-token`
3. สร้าง `.auth-cookie` (1 บรรทัด) ที่ root project:
   ```
   __Secure-authjs.session-token=eyJhbGc…(JWE token)
   ```
4. เพิ่มใน `.gitignore`:
   ```
   .auth-cookie
   .tmp/
   .cache/
   ```

> ⚠️ Cookie expire ทุก ~30 วัน. 401 = ต้อง re-login + update file

## First-run

```text
/update-products      # ~24 วินาที — สร้าง cache 4,300+ สินค้า
/broadcast โปรโมชั่นวิตามินซี 12 รายการ tag=VIP พรุ่งนี้ 10:00
```

## Refresh policy

- ทุก ~24 ชั่วโมง (`/broadcast` จะเตือนถ้า cache เก่ากว่านี้)
- ทันทีหลังพี่ทีม CNY อัพเดทโปรชุดใหม่
- ราคา/สต็อกใน cache = snapshot ตอน `/update-products` ครั้งล่าสุด

## Hard rules (lessons learned)

1. cookie = `__Secure-authjs.session-token` (NextAuth v5) — **ไม่ใช่** `next-auth.session-token` (v4)
2. ส่ง cookie ผ่าน `-H "Cookie: $(tr -d '\r\n' < .auth-cookie)"` (Windows curl `\r\n` issue)
3. `scheduledAt` = ISO UTC + `Z` (ใช้ `new Date(bkkStr).toISOString()`)
4. `targetTagIds` = `number[]` ไม่ใช่ `string[]` (Zod validation)
5. `flexContents` รับเฉพาะ flex messages; closing text → `content` field
6. `flexContents.length` ≤ 5 (LINE quota)
7. `scheduledAt` ≥ now + 2h (เว้นแต่ user confirm)
8. ห้าม POST ก่อน approve ชัดเจน
9. ห้าม curl LINE API ตรง — ใช้ inbox.re-ya.com แล้ว cron pipeline ส่งเอง
10. Cache > 24h → เตือนแล้วแนะนำ `/update-products`

## Troubleshooting

| Symptom | Fix |
|---|---|
| 401 Unauthorized | cookie expired → re-login + update `.auth-cookie` |
| `scheduledAt` rejected | ใช้ UTC `Z` format ไม่ใช่ `+07:00` |
| `targetTagIds` invalid_type | cast เป็น `Number(id)` ก่อน POST |
| `Invalid flexContent at index N` | ตรวจ index N ว่าเป็น flex (text ต้องไปอยู่ `content`) |
| `MISSING — run /update-products first` | ยังไม่ได้สร้าง cache → run `/update-products` |
| `xlsx skipped: cannot find module` | รัน `npm install` ใน plugin folder |
